# Descriptor-aware CLI listing

The list command now uses the existing instance-owned MessageFactory inventory.
It returns the union of canonical and successfully loaded GZ_DESCRIPTOR_PATH
types, sorted without duplicates. Environment paths may name accepted descriptor files or
one-level directories; loading and gz-msgs.gz_desc priority reuse the already
qualified registry behavior. The canonical schemas remain the registry's immutable base; duplicate schema
file names do not replace them. Native environment-first redefinitions of
canonical file names are outside this corpus. No new registry, process-global
state or dependency is introduced. The --list, -l and Rust list alias share this inventory.

Eleven native cases compare complete sorted names, status and stderr: unset and
empty environment, each descriptor file, combined/reversed/duplicate paths,
directories, the priority filename and ignored paths. Imported canonical types,
custom nested messages and synthetic map-entry names are included. The custom
schema's descriptor bytes are regenerated by protoc in Rust tests and native
replay. Original binary fixtures remain byte-for-byte unchanged. Native replay
binds the source commit, CLI source/binary, linked Gazebo/protobuf libraries,
canonical schema manifest and all fixture inputs.

Run `cargo test --locked --test cli_external` and
`python3 scripts/cli-list-reference.py`. Each command executes in a fresh process;
Rust tests set or remove only that child's environment. Temporary test inputs are
owned by the test and removed afterward. No global environment mutation occurs.

This slice qualifies valid-descriptor name sets, not native malformed-descriptor
console diagnostics. Library load errors remain structured and available through
MessageFactory::take_initial_errors; the list command does not print them. CLI
info remains limited to bundled native
Descriptor::DebugString output; arbitrary external definitions need separate
formatting work. Install-prefix discovery, global canonical-path caches, full
CLI grammar, non-UTF-8 argv and broader release/performance qualification remain
open. No original test mapping or MSG-02 acceptance is retired by this increment.

The full working gate passes 87 Rust checks, five snapshot regressions, archive
QA and the clean downstream consumer, with 1460/1462 owned lines and 2297/2311
regions. This includes the fixture provenance guard and regenerated descriptor
comparison. Independent review and matching strict staged/hosted qualification
remain pending; working measurements do not prove a published commit passed.
